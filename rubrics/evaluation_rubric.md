# Vietnamese AI Evaluation Rubric

## General criteria

| Criterion | What to check |
|---|---|
| Accuracy | The answer is factually correct and does not invent details. |
| Helpfulness | The answer addresses the user's request directly. |
| Language quality | Vietnamese is natural, clear, and grammatically appropriate. |
| Tone | The tone fits the context: formal, friendly, concise, or instructional as required. |
| Completeness | The response covers all required parts of the prompt. |
| Safety | The response avoids unsafe claims and gives appropriate caution when needed. |
| Consistency | The response does not contradict itself or the provided source. |

## Audio evaluation criteria

| Criterion | Notes |
|---|---|
| Pronunciation | Are vowels, consonants, tones, and word boundaries clear? |
| Fluency | Does the speech flow naturally without unnecessary pauses? |
| Intonation | Does pitch sound natural for a Vietnamese speaker? |
| Authenticity | Does the speech sound native, or does it feel machine-generated? |
| Intelligibility | Can the listener understand the message without repeated listening? |

## Rating scale
- **Excellent:** Clear, accurate, natural, complete.
- **Good:** Minor issues, still easy to understand.
- **Acceptable:** Understandable but noticeable weakness.
- **Poor:** Meaning is unclear or the task is not fulfilled.
- **Fail:** Wrong language, unsafe content, or unusable output.
