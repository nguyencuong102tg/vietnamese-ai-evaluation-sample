# Vietnamese AI Evaluation Sample

This repository contains **synthetic examples** for Vietnamese AI evaluation work. It is intended as a public demo for tasks such as Vietnamese language evaluation, AI audio evaluation, response ranking, and data quality review.

No real user data or confidential data is included.

## Contents
- `rubrics/evaluation_rubric.md`: criteria for rating Vietnamese AI outputs.
- `examples/audio_evaluation_samples.md`: sample audio evaluation feedback in English.
- `examples/response_ranking_samples.md`: sample response comparisons and ranking justifications.

## How to use
Use these as templates when practicing AI-evaluation assessments. Adapt the wording to the actual task guidelines, but keep feedback:
- short
- evidence-based
- clear
- consistent
